## Optimizaciones de Memoria y Rendimiento

Para resolver los problemas de overflow de memoria que ocurrían principalmente cuando el programa corría por mucho tiempo o se agregaban objetos dinámicamente, se implementaron mejoras críticas de rendimiento:

### Gestión Dinámica de Buffers SSBO
**Problema**: En cada frame del raytracing se creaban nuevos buffers Shader Storage Buffer Objects (SSBO) para matrices de transformación, material y primitivos, pero nunca se liberaba la memoria de los anteriores. Esto causaba crecimiento continuo de VRAM y RAM hasta causar crash.

```python
# Antes: Nueva creación cada frame (causiando leaks)
buffer = self.ctx.buffer(matrix.tobytes())

# Después: Reutilización de buffers existentes
if not hasattr(self, f'_buffer_{binding}') or getattr(self, f'_buffer_{binding}') is None:
    # Crear buffer por primera vez
    setattr(self, f'_buffer_{binding}', self.ctx.buffer(matrix.tobytes()))
else:
    # Reutilizar buffer existente, solo actualizar contenido
    existing_buffer = getattr(self, f'_buffer_{binding}')
    matrix_bytes = matrix.tobytes()
    if len(matrix_bytes) <= existing_buffer.size:
        # Suficiente espacio: copiar datos sin nuevo buffer
        existing_buffer.write(matrix_bytes)
    else:
        # Buffer pequeño: crear uno más grande
        setattr(self, f'_buffer_{binding}', self.ctx.buffer(matrix_bytes))

# Vincular el buffer (reutilizado o nuevo) al binding point de SSBO
getattr(self, f'_buffer_{binding}').bind_to_storage_buffer(binding=binding)
```

**Cómo se solucionó**: Se cambió la estrategia de crear buffers descartables cada frame por mantener referencias persistentes a los buffers SSBO, actualizando solo su contenido cuando cambian los datos. Esto evita la acumulación de buffers no liberados en memoria GPU.

### Límites Máximos de Objetos
**Problema**: No había restricción en la cantidad de objetos que se podían agregar, permitiendo crecimiento infinito de memoria.

**Cómo se solucionó**:
- Se agregó un parámetro `max_objects` (default 100) al constructor de `RaySceneGPU` en `src/scene.py`.
- Los métodos `add_object` ahora retornan False si se alcanza el límite.
- Se agregó información visual en la UI cuando no se pueden agregar más objetos.

### Actualización Condicional de Buffers GPU
**Problema**: Las estructuras de BVH y matrices se reconstruían en cada frame del render, incluso cuando la escena no cambiaba, consumiendo tiempo y memoria innecesariamente.

```python
# En add_object: cuando se agrega un objeto, marcar que necesita actualizar
self.objects.append(model)
self.graphics[model.name] = ComputeGraphics(self.ctx, model, material)
# Flag que indica que los buffers necesitan refresh
self._needs_buffer_update = True  # Fuerza reconstrucción de BVH y matrices

# En render(): solo actualizar cuando cambió algo
if (self.raytracer is not None):
    if self._needs_buffer_update:  # Verificar flag antes de reconstruir
        self.update_gpu_buffers()   # Reconstruir matrices y BVH
        self._needs_buffer_update = False  # Reset flag hasta próximo cambio
        self._cached_primitives = None     # Limpiar caché de primitivos
    self._update_matrix()  # Actualizar matrices en CPU
    self._matrix_to_ssbo() # Transferir a GPU (solo copia, no reconstrucción)
```

**Cómo se solucionó**: Se agregó un mecanismo de flags para detectar cuando realmente cambian los objetos, evitando reconstruir estructuras costosas del raytracing (BVH, matrices) en cada frame innecesariamente.

### Caché Inteligente para BVH
**Problema**: La jerarquía de Bounding Volume Hierarchy (BVH) se reconstruía cada frame, siendo una operación costosa para escenas complejas.

```python
def primitives_to_ssbo(self, primitives, binding = 3):
    # Verificar si las primitivos cambiaron desde la última reconstrucción
    if not hasattr(self, '_cached_primitives') or self._cached_primitives != primitives:
        # Solo reconstruir BVH si cambiaron los objetos (operación costosa)
        self.bvh_nodes = BVH(primitives)  # Crear nuevas cajas delimitadoras
        self.bvh_ssbo = self.bvh_nodes.pack_to_bytes()  # Serializar jerarquía
        # Actualizar caché para próximas comparaciones
        self._cached_primitives = primitives.copy() if hasattr(primitives, 'copy') else primitives[:]
    else:
        # Si no cambió, usar BVH existente (optimización)
        pass

    # Reutilizar buffer BVH (mismo patrón que matrices)
    if not hasattr(self, '_bvh_buffer'):
        self._bvh_buffer = self.ctx.buffer(self.bvh_ssbo)
    else:
        if len(self.bvh_ssbo) <= self._bvh_buffer.size:
            self._bvh_buffer.write(self.bvh_ssbo)  # Solo actualizar contenido
        else:
            self._bvh_buffer = self.ctx.buffer(self.bvh_ssbo)  # Nuevo buffer si necesario
    # Vincular buffer al shader compute
    self._bvh_buffer.bind_to_storage_buffer(binding=binding)
```

**Cómo se solucionó**: Se implementó comparación de estado entre frames para reconstruir la estructura BVH únicamente cuando cambian los objetos, con reutilización de buffers GPU para evitar creación repetida.

```glsl
// En raytracer.comp - Cálculo UV por cara del cubo
vec2 calculateCubeUV(vec3 position, vec3 normal) {
    vec3 absNormal = abs(normal);
    // Determina cara según normal dominante
    if (absNormal.x > absNormal.y && absNormal.x > absNormal.z) {
        return vec2(position.y + 0.5, position.z + 0.5);  // Cara X
    } else if (absNormal.y > absNormal.x && absNormal.y > absNormal.z) {
        return vec2(position.x + 0.5, position.z + 0.5);  // Cara Y
    } else {
        return vec2(position.x + 0.5, position.y + 0.5);  // Cara Z
    }
}

vec3 sampleTexture(vec2 uv, int objectIndex) {
```

```python
def _calculate_base_scale(self):
    """Calcular factor de escala base basado en el tamaño de la ventana"""
    base_width = 800
    base_height = 600
    width_scale = self.total_width / base_width
    height_scale = self.total_height / base_height
    geometric_mean = (width_scale * height_scale) ** 0.5
    base_scale = 1.0 / geometric_mean
    return max(0.6, min(1.0, base_scale))

def _get_scaled_button_width(self):
    """Calcular ancho de botón escalado"""
    base_width = 0.17
    base_ratio = 0.35
    panel_scale = self.panel_width_ratio / base_ratio
    return base_width * panel_scale * self.base_scale
```

```python
class PhysicsWorld:
    """Main physics world that coordinates all physics systems"""
    def __init__(self, gravity_strength: float = -9.81):
        self.gravity_system = GravitySystem(gravity_strength)
        self.collision_system = CollisionSystem()
        self.physics_objects: List[PhysicsObject] = []

    def update(self, delta_time: float):
        """Update physics simulation"""
        # Aplicar gravedad
        for physics_obj in self.physics_objects:
            self.gravity_system.apply_gravity(physics_obj, delta_time)

        # Resolver colisiones
        self._handle_collisions()

        # Integrar velocidades
        for physics_obj in self.physics_objects:
            physics_obj.obj.position += physics_obj.physics.velocity * delta_time
```

### 10. Optimizaciones de Rendimiento para Física
**Descripción**: Se implementaron optimizaciones específicas para mantener rendimiento en simulaciones físicas complejas.

**Optimizaciones**:
- **Timestep fijo**: Actualización física a 60 FPS constante
- **Detección de colisiones optimizada**: Uso de AABB para colisiones rápidas
- **Caché de estado**: Evitar cálculos redundantes
- **Límites de objetos**: Prevención de sobrecarga del sistema

**Implementación técnica** (`src/physics.py`):
```python
class PhysicsWorld:
    def __init__(self, gravity_strength: float = -9.81):
        self.fixed_timestep = 1.0 / 60.0  # 60 FPS physics
        self.accumulated_time = 0.0

    def update(self, delta_time: float):
        self.accumulated_time += delta_time
        while self.accumulated_time >= self.fixed_timestep:
            self._fixed_update(self.fixed_timestep)
            self.accumulated_time -= self.fixed_timestep
```
